# Impurity
Impurity is a divine horror bullet hell inspired by Touhou, Blasphemous, and quite a few others. It's made in Godot, with sprites and animations in Aseprite and music in FL Studio. The game will be fairly large, and a sequel is planned.

# How to Play
To move, use WASD. To sprint, hold X, and to slow down, hold Shift.
You will not be reset if you die.
This game only runs in the browser, at https://falsevanityyy.itch.io/impurity.
